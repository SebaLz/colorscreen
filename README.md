# Color Screen

Pantalla-luz para videollamadas, foto y decoración. Tocá un color, mezclá, aplicá un estilo y abrilo en fullscreen.

**https://colorscreen.sebastianalcaraz.com**

## Qué hace

- Color sólido con pad HSL, hex, RGB, eyedropper y random
- Mix de 2–4 colores (uniforme o fundido)
- Degradé linear/radial, split warm/cool, blancos Kelvin 1800–7500K
- 30 estilos: videollamada, blancos, escenas y utilidad
- Brillo, softbox, grano, warm/cool, animaciones (breathe, pulse, flicker, aurora)
- Fullscreen, wake lock, timer, favoritos, recents y links compartibles
- PWA (`display: fullscreen`)

## Dev

```bash
npm install
npm run dev
npm run build
```

Atajos: `F` fullscreen · `H` / espacio oculta UI · flechas matiz/brillo · `R` random · `S` share · `C` copia hex · `1–8` estilos.
